# RouteQuest ✈️

**RouteQuest** is an iOS app that recommends real-world airline routes to fly, based on a curated dataset of actual airline routes operated by real carriers — from the Singapore–JFK ultra-long-haul to the 15-minute hop between Denver and Colorado Springs.

> 🤖 **This app was 100% coded by AI** — every line of Swift, the recommender engine, the bundled dataset, the build scripts, and this README were generated by an AI agent (Vibe, powered by GLM). No human wrote any of the code.

## What it does

- 🔍 **Route Discovery** — browse a hand-curated dataset of 50+ real airline routes (airline, aircraft type, distance, tags).
- 🧠 **Smart Recommendations** — the recommender engine scores every route on distance, rarity of aircraft type, tag appeal, and your own fly history, then ranks what you should fly next.
- 🏷️ **Filter by vibe** — ultra-long-haul, A380, polar routes, oceanic crossings, scenic shorts, and more.
- ✅ **Track your flights** — mark routes as flown; your stats (miles, airlines, countries) update live.
- 📊 **Stats dashboard** — total km flown, completion %, regions visited.

## Building (Xcode)

1. Install [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`
2. Run `xcodegen generate`
3. Open `RouteQuest.xcodeproj`, pick your team, and hit Cmd+R.

## Installing via LiveContainer 📱

[LiveContainer](https://github.com/hugeBlack/LiveContainer) lets you sideload and run multiple IPAs without a computer after the initial setup, and without app limits.

### Step 1 — Build the unsigned IPA

```bash
./scripts/build_ipa.sh
# Output: build/RouteQuest.ipa (unsigned, LiveContainer will sign it)
```

Or manually:

```bash
xcodegen generate
xcodebuild -project RouteQuest.xcodeproj -scheme RouteQuest \
  -configuration Release -sdk iphoneos \
  CODE_SIGN_IDENTITY="" CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=NO \
  -derivedDataPath build/DerivedData
mkdir -p build/Payload
cp -r build/DerivedData/Build/Products/Release-iphoneos/RouteQuest.app build/Payload/
cd build && zip -r RouteQuest.ipa Payload && cd ..
```

### Step 2 — Get the RouteQuest.ipa onto your device

- AirDrop it, save it from iCloud Drive, or download it straight from the [Releases](../../releases) page in Safari on your iDevice.

### Step 3 — Import into LiveContainer

1. Open **LiveContainer** on your device.
2. Tap the **+** button (Install IPA) in the toolbar.
3. Pick the `RouteQuest.ipa` file you saved.
4. LiveContainer will automatically **re-sign the app with the certificate LiveContainer was set up with** — you don't need to sign it yourself.
5. Launch RouteQuest from inside the LiveContainer library (or the "HideMyApp" multitasking switcher it installs).
6. If it crashes on first launch, enable **"Don't Kill" / persistence** for the app inside LiveContainer settings.

> ⚠️ LiveContainer requires that you already set it up by side loading its IPA (AltStore, Sideloadly, or a signing service) — see [LiveContainer's README](https://github.com/hugeBlack/LiveContainer) for one-time setup.

## Data

All routes in `RouteQuest/Resources/routes.json` are real airline routes flown today (or historically iconic ones). Distances are great-circle approximations. The dataset is intentionally compact so the app works fully offline — no network calls, no tracking.
