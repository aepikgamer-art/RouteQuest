# RouteQuest

**RouteQuest** is an iOS app that recommends real-world airline routes to fly, based on a curated dataset of actual airline routes operated by real carriers - from the Singapore-JFK ultra-long-haul to the 15-minute hop between Denver and Colorado Springs.

> **This app was 100% coded by AI** - every line of Swift, the recommender engine, the bundled dataset, the build scripts, and this README were generated by an AI agent (Vibe, powered by GLM). No human wrote any of the code.

## What it does

- **Route Discovery** - browse a hand-curated dataset of 50+ real airline routes (airline, aircraft type, distance, tags).
- **Smart Recommendations** - the recommender engine scores every route on distance, rarity of aircraft type, tag appeal, and your own fly history, then ranks what you should fly next.
- **Filter by vibe** - ultra-long-haul, A380, polar routes, oceanic crossings, scenic shorts, and more.
- **Track your flights** - mark routes as flown; your stats (miles, airlines, countries) update live.
- **Stats dashboard** - total km flown, completion %, regions visited.
- **ICAO codes** - switch between IATA (ATL) and ICAO (KATL) codes anywhere in the app.
- **Races** - pick an airport as the finish line and watch a live leaderboard of real flights racing to land there, powered by the Flightradar24 API or FlightAware AeroAPI.
- **Liquid Glass** - the new iOS 26 glass design, with graceful fallback on older iOS versions.
- **Appearance** - System / Light / Dark theme setting.

## Building (Xcode)

1. Install [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`
2. Run `xcodegen generate`
3. Open `RouteQuest.xcodeproj`, pick your team, and hit Cmd+R.

## No Mac? Build it in the cloud

This repo ships a **GitHub Actions workflow** (`.github/workflows/build-ipa.yml`) that builds the unsigned `RouteQuest.ipa` on a free macOS runner (Xcode 26, needed for Liquid Glass) on every push to `main`. Just:

1. Open the [Actions tab](../../actions) and run **Build IPA** (or push any commit).
2. Grab `RouteQuest.ipa` from the run's **Artifacts**, or from the [Releases](../../releases) page (`build-latest` tag).
3. Download it on your iPhone and import into LiveContainer - see below.

## Installing via LiveContainer

[LiveContainer](https://github.com/hugeBlack/LiveContainer) lets you sideload and run multiple IPAs without a computer after the initial setup, and without app limits.

### Step 1 - Get the IPA

Download the unsigned `RouteQuest.ipa` from the [Releases](../../releases) page (`build-latest`) in Safari on your iPhone, or from the latest Actions run's artifacts.

### Step 2 - Import into LiveContainer

1. Open **LiveContainer** on your device.
2. Tap the **+** button (Install IPA) in the toolbar.
3. Pick the `RouteQuest.ipa` file you saved.
4. LiveContainer will automatically **re-sign the app with the certificate LiveContainer was set up with** - you don't need to sign it yourself.
5. Launch RouteQuest from inside the LiveContainer library.
6. If it crashes on first launch, enable **"Don't Kill" / persistence** for the app inside LiveContainer settings.

> LiveContainer requires that you already set it up by sideloading its IPA (AltStore, SideStore, or a signing service) - see [LiveContainer's README](https://github.com/hugeBlack/LiveContainer) for one-time setup.

## Add RouteQuest as a Source (SideStore / AltStore)

Point SideStore or AltStore at this repo's source manifest:

```
https://raw.githubusercontent.com/aepikgamer-art/RouteQuest/main/apps.json
```

- **AltStore**: Sources -> **+** -> same URL -> Browse -> RouteQuest -> **Install**.
- **AltStore PAL** users can also sideload the IPA directly: download `RouteQuest.ipa` from the [release](../../releases/tag/build-latest), then in AltStore PAL: **+** -> choose the downloaded IPA.

## Flight data (Races)

The Races tab pulls live flight data from either:

- **Flightradar24 API** - https://fr24api.flightradar24.com
- **FlightAware AeroAPI** - https://www.flightaware.com/aeroapi/

Add your API key for either (or both) in the Settings tab. Keys are stored only on your device. No key, no race - the app works fully offline everywhere else.

## Data

All routes in `RouteQuest/Resources/routes.json` are real airline routes flown today (or historically iconic ones). Distances are great-circle approximations. The dataset is intentionally compact so the app works fully offline - no network calls, no tracking.
